# SambaNAS2 changelog style (source of truth for automation)

This file supplements `.github/CHANGELOG_TEMPLATE.md`. The template describes a
generic `Added/Changed/Fixed` layout with dates; `sambanas2/CHANGELOG.md`
actually uses the emoji layout below with calendar RC versions and no dates.
Automation (and human edits) must follow this file.

## Headings

- Top is always `## Unreleased` (empty when nothing pending).
- Versioned headers are bare RC/release versions, no date:
  `## 2026.9.0-rc15`, `## 2026.9.0`, `## 2026.9.0-beta.42`. Never append dates.
- `config.yaml:version` (C) is source of truth. Rules:
  - `C == H` (first `##` != `Unreleased`): append to `## Unreleased` only (Us1/Us4).
  - `C` not in file + `Unreleased` non-empty: promote `Unreleased → ## C`,
    leave a new empty `## Unreleased` on top (Us2/Us3).
  - `C` already in older `##`: do not duplicate, only ensure `## Unreleased` exists.
  - `mergerelease/*`, `beta`, `prerelease/*` never contain `## Unreleased`
    (S2 = S1 minus the `Unreleased` line).

## Sections (only when non-empty, in this order)

- `### ✨ Features`
- `### 🐛 Bug Fixes`
- `### 🏗 Chore`
- `### 💥 Breaking Changes`
- `### 🔄 Migration Notes`
- `### 🚨 Notes`
- `### 🙏 Thanks` (keep short, release entries only)
- `### 🐭 Features from SRAT [vX](https://github.com/dianlight/srat)` (managed)

## SRAT subsection

- Deterministic base comes from `sambanas2/scripts/update_srat_changelog.sh`
  (reads `Dockerfile ARG SRAT_VERSION`, fetches that tag's `CHANGELOG.md`,
  demotes headers, strips `🙏 Thanks` / `📅 Roadmap`).
- AI/human curation on top: keep only user-important breaking, features and
  fixes; drop internal churn, duplicates of parent bullets, and noise.
- Never hand-edit the `🐭` header version; bump `ARG SRAT_VERSION` instead and
  re-run the script.
